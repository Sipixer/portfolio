# sylvainrougie.fr

Portfolio et CV de Sylvain Rougié, en Astro + Tailwind CSS.

```bash
bun install
bun run dev   # http://localhost:4321
bun run cv    # régénère public/cv-sylvain-rougie.pdf et la version texte
```

Le contenu du site et des deux CV vient d'un seul fichier : `src/data/profile.ts`.
